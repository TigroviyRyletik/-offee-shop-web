# Coffee Shop Website

## 📌 Project Description

This project is a full-featured web application for a coffee shop.
It is being developed using **C# (ASP.NET Core)** and **SQL** as the main technologies.

The goal is to create a modern, user-friendly website that allows customers to browse the menu, view detailed product information, and place orders online.

---

## ⚙️ Tech Stack

* **Backend:** C# (ASP.NET Core)
* **Database:** SQL Server
* **Frontend:** (planned) HTML, CSS, JavaScript / possibly React
* **Version Control:** Git + GitHub

---

## 🚀 Planned Features

### 1. Home Page

* Overview of the coffee shop
* Promotions or featured products
* Navigation to main sections

### 2. Menu

* List of drinks and food
* Prices and short descriptions
* Categories (coffee, tea, desserts, etc.)

### 3. Product Details

* Full description of each item
* Ingredients
* Images
* Price display

### 4. Order System (Planned)

* Add items to cart
* Place an order
* Basic checkout flow

### 5. Additional Features (Planned)

* User authentication (login/register)
* Admin panel for managing menu items
* Order history
* Responsive design

# Coffee Shop Website (Русская версия)

## 📌 Описание проекта

Этот проект — полноценное веб-приложение для кофейни.
Он разрабатывается с использованием **C# (ASP.NET Core)** и **SQL**.

Цель — создать современный и удобный сайт, на котором пользователи смогут просматривать меню, получать подробную информацию о товарах и оформлять заказы онлайн.

---

## ⚙️ Технологии

* **Backend:** C# (ASP.NET Core)
* **База данных:** SQL Server
* **Frontend:** (планируется) HTML, CSS, JavaScript / возможно React
